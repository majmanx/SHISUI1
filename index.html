石髓 · 使用指南

一台把中国弦管乐器"插上电"的合成器。左手是石头与真空管，右手是π与放射性衰变。

三层界面

  • 玩：只看四个宏旋钮、XY 板、随机接口和键盘。先玩，不用懂。
  • 塑：加上乐器建模、插电/毒液、放大器、效果与琶音。
  • 深：调制矩阵、LFO、代码台、音色 JSON。全部可见。

旋钮

  • 上下拖动或滚轮调节；Shift 微调；双击复位；右键 🔒 锁定（"惊喜"随机化会跳过它）。
  • 旋钮外圈的彩色弧线与光点 = 当前被调制的实际值。
  • 找不到？Ctrl/⌘+K 输入中文/英文名，回车直接跳过去并闪一下。

随机接口 R1–R4

  • 四个"接口"各输出一个 0..1 的数，来源可选：真随机（crypto）、圆周率（即时计算的 π 数字流，每次取 4 位）、碳-14（泊松过程模拟的放射性衰变，半衰期 5730 年，样本会真的越来越少）。
  • 按"刷新"或空格取新数；"自动刷新"按频率取；碳-14 源下，每一次衰变事件会轮流刷新一个接口。
  • 点一个接口（或 LFO / 衰变脉冲 / XY / 宏 芯片），再点任意旋钮 → 完成一条调制接线；在"深"模式的矩阵里改深浅或删除。
  • "衰变触发"让每次衰变按概率弹出一个五声音阶的音；"盖革咔嗒"让你听见它。
  • 四个接口是舷窗：随机源是真随机 / π 时，窗里是阳光的高度与亮度；碳-14 源时，窗里是矿石里发光碳晶的含量。数值越大越亮 / 越满。
  • 叠得太顶了：复位 把接口数值归零并重置样本；断开 拆掉所有随机接线；接口深度 整体收小随机调制。

插电 / 放大链

  • 乐器 → 拾音器（非对称饱和 + 可叠加振荡器层与次低音）→ 滤波 → 二极管削波（Shockley 曲线，锗/硅不对称）→ 电子管（三极管传输曲线、栅偏压、电源下垂、交越失真、输出变压器）→ 箱体 → 合唱 → 乒乓延迟 → 石厅混响 → 压缩。
  • 毒液：反馈 FM、波折叠、采样碎裂、液态漂移，配黑曜石界面。宏 4 默认就是它。

毒液模式

顶栏毒液开关旁的"毒?"按钮会打开完整的玩法引导（第一次打开毒液也会自动弹出）。

原声 · 全部重置

乐器面板里的 🎐 原声 把当前乐器恢复为最接近真实乐器的设置，并写出它像哪件传世乐器、为什么；⟲ 全部重置 两次确认后把所有旋钮、接线、随机接口、宏恢复出厂（我的预设与声音槽不受影响）。

停下来 · 素面 · 报错

  • 随机接口面板有 ⏸ 暂停衰变（碳-14 时钟停住，不再有衰变事件、不再自动刷新）和 ■ 停止随机（暂停 + 关掉自动刷新、衰变触发与碳衰变琶音）。
  • 顶栏 素面 Plain 关掉大理石纹理与光晕，省电清爽，再点恢复。
  • 顶栏 报错 Report 收集最近的错误与操作记录，加上你的描述，生成 GitHub Issue 给开发者。

语言

顶栏"中 · EN / 中 / EN"切换显示语言：双语、只中文、只英文。选项、旋钮、按钮全部跟随。

代码台

在"深"模式底部。note('C4')、every(0.25, fn)、seq('C4 E4 . G4')、set('flt.cutoff', 800)、pi(i)、c14()、onDecay(fn)、mod('R1','gz.pos',0.5)…点 API 查看全部。Ctrl/⌘+Enter 运行。

快捷键

电脑键盘像钢琴一样两排：Z X C V B N M 是低八度白键，S D G H J 黑键；Q W E R T Y U I O P [ ] 高八度白键，2 3 5 6 7 9 0 = 黑键。,/. 移八度 · 空格 刷新接口 · Ctrl/⌘+Z 撤销 · Esc 关闭/取消指派，连按两次全部静音 · MIDI 键盘即插即用（延音踏板 CC64、调制轮 = WHEEL 源、CC74 = 截止、弯音）。先点一下页面，光标不在文本框里时键盘才会发声。

录音与声音槽

  • 底部"录音 · 声音槽"面板：按 ● 开始录，录的是你听到的最终输出（含效果与正在播放的槽）。停止后自动进入下一个空槽。
  • 8 个槽：▶ 播放 / 循环 / 音量 / 速度（变调）/ 过效果链 / ⬇ 导出 WAV / 导入你自己的音频。一边循环几个槽一边弹奏再录，就是在用旧素材叠出新音色。
  • 槽保存在本浏览器的 IndexedDB 里，刷新或下次打开自动恢复；✕ 清空并删除存档，录到已占用的槽会直接替换。换浏览器或要备份请导出 WAV。音色本身会自动记住上次状态，也可以"存预设"。

毒液模式 · VENOM MODE

把一件温润的中国乐器灌进液态黑曜石。毒液不是一个效果器，而是一整套"过载的生命体"：反馈 FM 让弦自己咬自己，波折叠 把泛音折成金属棱角，碎裂 降低采样与位深，流淌 让音高像熔金一样缓慢漂移。界面同时变成黑曜石与酸绿脉络，提醒你现在弹的是另一种生物。
Venom pours a Chinese instrument into liquid obsidian: feedback FM, wave folding, sample crushing and slow pitch ooze, all at once. The UI turns to obsidian so you know you are playing a different creature.

官方玩法 · 三步领进门

  1. 先开小火：打开毒液后把宏旋钮 毒 · Venom 转到 20% 左右，弹一个长音，听到弦开始"发烫"即可。Turn macro 4 to ~20% and hold a note until the string starts to "heat up".
  2. 再加咬合：在"插电 · 毒液"面板里把 反馈FM 和 折叠 各推到 40–60%，配合 次低音 得到"斗破"的底气。太脏就降 碎裂。Raise Feedback FM and Fold to 40–60%, add Sub for weight; lower Crush if it gets too dirty.
  3. 最后让它活过来：把随机接口 R1 接到 折叠，随机源选 碳-14，开"衰变触发"。每一次衰变都会改变毒液的形状。Route port R1 to Fold, choose the C-14 source and enable decay triggering: every decay reshapes the venom.

适合的乐器

二胡 + 单音连奏 + 长滑音最像活物；古筝 + 摇指 + 折叠像被电流穿过的钢弦；唢呐 + 喇叭口 + 电子管是最"顶"的组合。Erhu with mono legato and long glide feels most alive; guzheng tremolo with folding sounds like electrified steel; suona with bell and tube drive is the loudest combo.

控制不住的时候

随机接口面板有 复位（接口数值归零）和 断开（拆掉所有随机接线），接口深度 旋钮可以整体收小随机调制；顶栏 ✕ 全部静音；Ctrl/⌘+Z 撤销。Use Reset / Unroute / Port depth in the Random bay, ✕ to panic, Ctrl/⌘+Z to undo.

"带我玩"会载入"毒液胡"预设、切到"塑"模式并点亮毒液面板。
